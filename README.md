# FastAPI_shop
Интернет-магазина на FastAPI, используя асинхронную работу с базой данных PostgreSQL через AsyncSession, SQLAlchemy и драйвер asyncpg. Проект охватывает ключевые функциональности для управления пользователями и товарами, с акцентом на безопасность и удобство тестирования.

Возможности:
Регистрация и аутентификация:

Реализован эндпоинт POST /users/ для создания пользователей с ролями "seller" и "buyer".
Настроили POST /users/token для выдачи JWT-токенов: access_token (30 минут) и refresh_token (7 дней).
Использован OAuth2PasswordBearer для аутентификации через логин и пароль.
Управление товарами:

Создан эндпоинты (например, POST /products/, GET /products/) для CRUD-операций с товарами.
Реализовали проверку роли "seller" через get_current_seller и привязку товаров к продавцу (seller_id).
Обновление токена:

Создан эндпоинт POST /refresh-token, чтобы обновлять refresh_token. А также, в виде домашнего задания, вы должны были реализовать эндпоинт, который принимает refresh_token и возвращает новый access_token.
Безопасность:
Проверяем is_active == True для пользователей при аутентификации и обновлении токена.
Использован SECRET_KEY для подписи и валидации JWT.
